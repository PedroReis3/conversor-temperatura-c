# Conversor de Temperatura em C

Projeto desenvolvido em linguagem C para praticar estruturas de decisão, laços de repetição e operações com números decimais.

## Funcionalidades

- Celsius para Fahrenheit
- Fahrenheit para Celsius
- Celsius para Kelvin
- Kelvin para Celsius
- Classificação de temperatura
- Menu interativo
- Repetição de conversões

## Classificação

- Muito frio (< 10°C)
- Frio (< 20°C)
- Agradável (< 30°C)
- Quente (< 35°C)
- Muito quente (>= 35°C)

## Conceitos praticados

- float
- switch
- if / else if
- while
- do while
- Validação de menu
